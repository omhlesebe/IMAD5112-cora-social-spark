 Purpose of the App
Cora's Social Sparks is a simple Android app designed to help users get conversation starter ideas for different times of the day. The user selects a time period (Morning, Afternoon, or Dinner) and the app provides a fun, friendly social tip. It also has an option to show the current time greeting.

 How to Use the App
1. Open the app
2. You will see "Cora's Social Sparks" welcome screen
3. Enter text or click buttons for:
   - *Morning* - Shows morning conversation starters
   - *Afternoon* - Shows afternoon social sparks
   - *Dinner* - Shows dinner table topics
4. Click Show to display the spark
5. The app displays a personalized message based on time of day

 Features
- Clean and simple UI using ConstraintLayout
- Three time-based categories (Morning, Afternoon, Dinner)
- Interactive buttons with Toast messages
- Kotlin implementation in MainActivity.kt

 Technical Details
- *Language:* Kotlin
- *IDE:* Android Studio
- *Min SDK:* 24
- *Layout:* activity_main.xml
- *Main Logic:* MainActivity.kt handles button clicks and time logic
